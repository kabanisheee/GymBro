# Дневник зала: свой сайт без регистрации

Данные хранятся в браузере вашего телефона. Никаких аккаунтов и баз данных.

## 1. Сохраните данные из приложения в Claude
Приложение в Claude → Настройки → Данные → **Экспорт**. Сохраните файл `gym-diary-….json` на телефон.

## 2. Опубликуйте сайт на GitHub Pages (бесплатно, один раз)
Удобнее с компьютера, но можно и с телефона.
1. Зарегистрируйтесь на https://github.com.
2. Справа вверху **+ → New repository** → имя `gym` → **Public** → **Create repository**.
3. Нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите **всё содержимое папки** (файлы и папку `icons`) → внизу **Commit changes**.
5. Вверху репозитория **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/gym/`.

## 3. Установите на телефон
1. Откройте адрес в Chrome на телефоне.
2. ⋮ → **Установить приложение** (или «Добавить на главный экран»). Появится иконка со штангой.
3. Откройте приложение с иконки → Настройки → Данные → **Импорт** → выберите файл из шага 1.

## Важно
- Данные живут только в этом браузере на этом телефоне. Если очистить данные Chrome или сменить телефон, они пропадут.
- Поэтому раз в неделю делайте **Настройки → Данные → Экспорт** и храните файл, например в облаке или Telegram «Избранное».
- На новый телефон данные переносятся так же: Экспорт на старом, Импорт на новом.
